# DISPATCHER

Проект команды AIM на спринт «К.О.Н.Т.У.Р.»

## Описание игры

События игры разворачиваются во вселенной К.О.Н.Т.У.Р. В этом мире грибок О-41 поглощает бетон, превращая захваченные строения в лиминальные пространства.

Вы принимаете на себя роль диспетчера секретного отделения службы спасения метро.
Вы работаете на тайную организацию, и ваша цель - спасать людей, попавших на искажённые аномалиями станции метро, захваченных грибком.

Игра представляет собой визуальную новеллу, при каждом прохождении которой будут появляться случайные герои истории.
Всего представлено 3 станции для прохождения. **Попытайтесь спасти всех!**

В процессе разработки на игровом движке Unreal Engine 4.27 была реализована собственная система диалогов и ветвлений c поддержкой навигации через клавиатуру.

## Установка и удаление игры

Скачать архив `.zip` с вкладки релизов репозитория. Распаковать в удобное место и запустить `.exe` файл.
Для удаления игры достаточно переместить распакованную папку в корзину.

Также версию игры, представленную на геймджеме, можно найти на [сайте проведения](https://dustore.ru/g/223).
